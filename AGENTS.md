# Usta Renovasyon Repository Rules

Bu repository bağımsız GitHub Pages sitesidir.

- Harici uygulama-builder bağımlılığı ekleme.
- Sunucuda veri tutulduğu izlenimi veren sahte form başarısı üretme.
- Formlar yalnızca WhatsApp üzerinden gerçek kullanıcı teslimine yönlenir.
- Yönetim paneli, giriş/kayıt ve gereksiz backend ekleme.
- `ustarenovasyon.com` public site davranışı ve SEO yollarını koru.
